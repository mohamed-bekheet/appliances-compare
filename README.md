
## 🏆 ترشيح أفضل قيمة مقابل السعر (الغسالات)
لما الفلتر الحالي فيه غسالتين أو أكتر، الموقع بيعرض لوحة ترشيح: أفضل قيمة، وأعلى جودة، وبديل قوي، والأرخص.

- **درجة الجودة**: نوع الموتور (دفع مباشر 25، انفرتر 18، غير محدد 10) + اللفات (حتى 10) + السعة (2 لكل كيلو، حتى 26) + بخار 5 + Wi-Fi 3 + مجفف 6 + ضمان موتور 10 سنين 5 + بلد الصنع (أوروبا 8، تركيا/مصر 6، غير محدد 4) + سمعة الماركة وشبكة الصيانة (**تقديري**، حتى 10) + تقييم العملاء (التقييمات الأقل من 3 بتاخد نص الوزن).
- **مؤشر القيمة** = الجودة ÷ السعر، والأفضل في الفلتر الحالي بياخد 100.
- أوزان سمعة الماركات موجودة في `BRAND_TIER` جوه `index.html` ولو حابب تعدّلها عدّلها من هناك.
- `made_in_verified: false` معناها إن بلد الصنع **مش مؤكد** من مصدر رسمي.

## 📈 سجل الأسعار ونفس الموديل في أكتر من محل
- كل منتج ليه رقم موديل حقيقي بياخد `product_key` (الماركة + رقم الموديل). أي منتجين ليهم نفس المفتاح بيتعتبروا **نفس المنتج** مهما كان المحل.
- كل listing (منتج × محل) فيه `history`: قائمة `{date, price, price_before, in_stock}` و`first_seen` و`last_seen`.
- المنتجات اللي من غير رقم موديل (زي إعلانات بي.تك القديمة) مش بتتجمع. لو عرفت إنها نفس المنتج اكتب `product_key` بإيدك.

### تحديث الأسعار
```bash
python3 tools/upsert.py new_items.json --date 2026-11-12
```
`new_items.json` = قائمة منتجات بنفس شكل data.json (من غير `id`):
- لو نفس الموديل في نفس المحل موجود → بيتضاف سعر جديد للسجل (لو السعر أو السعر القديم أو التوفر اتغير)، وبيتحدث `last_seen`.
- لو مفيش رقم موديل → بيدور على نفس المحل + الماركة + الفئة + الاسم.
- غير كدا → بيتضاف كمنتج جديد، والسكربت بيطبعلك لو نفس الموديل موجود في محلات تانية.

### في الموقع
- تحت اسم المحل: "🏪 في N محلات · الأرخص …". اضغط عليه يفتحلك جدول المحلات ورسم بياني لتطور السعر.
- ▼/▲ جنب السعر = التغير من آخر تسجيل.
- "📦 دمج نفس الموديل" = يعرض كل موديل مرة واحدة بأرخص سعر متاح (والترشيح بيشتغل على النتيجة دي).

## 🔄 التحديث الأسبوعي للأسعار
- `python3 tools/to_check.py` بيطلع قائمة المنتجات اللي ليها رابط، والأقدم تحديثاً في الأول.
